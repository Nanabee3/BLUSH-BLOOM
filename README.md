
# BLUSH & BLOOM

## Online Parlour Appointment Booking System

A BCA 4th Semester academic project developed by two students.

### Technologies
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- PDO
- Apache (XAMPP)

### Modules
1. Customer
2. Admin
3. Beautician

### Project Purpose
To provide an online platform where customers can explore beauty services and book parlour appointments conveniently.
